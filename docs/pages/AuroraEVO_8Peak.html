8 Peak Bead Tracking — Aurora EVO (5L)

Spectral QC: instrument-performance tracking from RCP-30-5A beads

Published

June 29, 2026

Secondary QC for the Cytek Aurora EVO from RCP-30-5A 8-peak beads. Note on the Aurora: daily QC adjusts each APD’s gain to pin bead MFI to a target, so raw MFI is held ~constant by design — the informative signals are the ones gain can’t compensate: sensitivity (Q & B), resolution, %CV, linearity, and spectral-signature stability. Heavy FCS processing is done once by scripts/Process8Peak.R; this page reads the peak_metrics.csv archive (+ the daily-QC gain) so it stays light.

Detail

Sensitivity (Q & B)

Q = detection efficiency (photoelectrons per unit signal, gain-normalised) — a drop means the detector collects less light per event. B = background/noise term; intrinsic CV = the high-signal noise floor (bead + optics). Estimated per detector from CV² vs 1/MFI across the resolved peaks. Because Q = 1/slope blows up when the slope nears zero, fits that are ill-conditioned — near-flat or negative slope, R² < 0.8, a non-monotonic CV profile, or a brightest-peak CV > 15% (e.g. a laser-instability run) — are suppressed (left blank) rather than reported as a phantom Q spike; the underlying cause then shows in the %CV panel.

NoteMethod & provenance — read me

This is the Q–B detector-sensitivity model of Hoffman & Wood (Wood JC, Cytometry 1998;33:260–266; Wood & Hoffman, Cytometry 1998;33:256–259; Chase & Hoffman, Cytometry 1998;33:267–279; Hoffman & Wood, Current Protocols in Cytometry Unit 1.20, 2007), the same model behind Spherotech’s STN-17 and BD’s CS&T Qr/Br (BD app note “Qr and Br in BD FACSDiva Software”, 2012). Total spread decomposes as CV² = CV_intr² + (1/Q)(1/S) + (B/Q)(1/S²); fitting CV² vs 1/S gives intrinsic CV (intercept), 1/Q (linear term) and B/Q (curvature) — algebraically identical to BD’s SD² = (1/Q)·S + B/Q fit with Q = 1/slope, B = Q·intercept (the MEF table’s true_b), and to STN-17’s closed form.

These panel-wide values use gain-normalised MFI (S = MFI/gain), not MESF, so Q and B are a relative, non-normalised index — not absolute MESF units. This is deliberate and is the intended use: BD reports its own Qr/Br in relative ABD units, and explicitly states that non-normalised Qr “values are still valid and serve as a powerful metric for tracking changes in detector performance over time” — a 50% change in a non-normalised Qr equals a 50% change in a normalised one. So treat these for single-detector trend monitoring (Levey-Jennings), not for cross-detector or cross-instrument comparison, and expect small steps when a bead lot changes. Absolute, gain-independent sensitivity lives in the MEF-unit Q/B and detection-limit (MEF) panels below, on the anchor detectors.

Fold-change maps: beside each absolute map, a companion normalises every detector to its own reference, stripping out absolute magnitude so dim and bright detectors are directly comparable and the colour isn’t dominated by the few brightest. The reference has two modes (set by fc_ref_window in the load chunk):

  • Dynamic / preliminary (current): reference = each detector’s best run so far. Good while characterising, but it shifts retroactively as runs accumulate, so it can’t anchor a stable trend.
  • Locked: once ~8–10 qualified runs exist, set fc_ref_window to a date range of known-good runs. The per-detector robust centre (median) ± SD over that window is frozen to data/reference/EVO_8peak_reference.csv, and the maps switch to a two-sided deviation-from-qualified-normal view (red = worse, in log₂ and SD units) where real drift and control-limit breaches emerge against a fixed anchor.

Q & B in MEF units (anchor detectors)

The Q/B heatmaps above are in gain-normalised MFI units — comparable across the full 64-detector panel, but arbitrary. On the anchor detectors (where lot AS01 gives a per-peak MEF) the same CV² regression can be run against true MEF, yielding Q and B in absolute, gain-independent units that match the Spherotech STN-17 definition. Because daily QC re-gains each detector, this MEF-anchored sensitivity is the more defensible cross-day metric: it re-anchors to the bead lot’s physical scale rather than trusting the recorded gain. The intrinsic CV (high-signal floor) is scale-invariant, so it should agree between the two fits — a built-in consistency check.

The regression above uses peaks 2–8 (every resolved peak). As an independent check, the literal STN-17 closed form uses just three populations — the blank (peak 1), one dim bead (peak 2) and the brightest (peak 8). The blank carries no assigned MEF, so it is extrapolated through the per-run calibration, MEF_blank = 10^((log10(MFI_blank) − a) / b), then Q = 1/(CV²_blank × MEF_blank). The two Q estimates won’t match exactly (3-point algebra vs. multi-point fit) but should track each other; large divergence flags a nonlinear detector.

%CV & noise floor

Peak 8 (brightest) uses robust %CV — it has a well-defined mean (~1–2% when healthy). The blank (peak 1) uses its absolute robust spread (IQR/1.349), not %CV: the blank sits near zero, so %CV explodes when the mean dips toward zero even though the actual spread is unchanged (e.g. UV8 on 2026-05-29). A rising blank spread is a genuine noise-floor increase.
